# Release Checklist

Back to [[Home]] · Use this every time you share an update.

- [ ] Play the new version for a few minutes in the browser: https://davidvstuhl-prog.github.io/Valley-Life/
- [ ] Try it on a touchscreen if you can
- [ ] Download the newest `.exe` from https://github.com/davidvstuhl-prog/Valley-Life/releases/latest and open it
- [ ] Check that old saves still load
- [ ] Update itch.io: download `ValleyLife-web.zip` and `ValleyLife-Windows.zip` from Releases and replace the old uploads
- [ ] Write a short devlog post on itch.io about what's new (copy from [[Changelog]])
- [ ] Tick off the finished items in [[Roadmap]]
